Ribbon Helper is live

For those looking to ribbon master their cherished Pokémon before Pokemon Bank closes down, I created a tool to help look up battle and contest info to make it as accessible as possible. There is also a full set of guides for all ribbons, resources for figuring out which games Pokemon can go to, and a tool to create a single HOME screenshot.
